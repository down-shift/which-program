# Limitations and next steps

Only ordinary filesystem-backed `.py` modules are supported. Custom loaders, native extensions, subprocesses that remove the injected environment, and hostile instrumentation tampering are not secured. Child Python processes inheriting environment variables are instrumented; wrappers that discard the environment may be detected only as missing records. The smoke workflow uses `uv venv`, `uv run`, and local wheel artifacts, and assumes a POSIX-style `venv/bin/python`. The minimal scripted adapter does not model a real agent. Automatic claim annotations are provisional. The evaluator currently uses an isolated source-root environment rather than a container and does not provide OS-level containment. Validate clean imports and all mismatch modes before a real-agent pilot.
